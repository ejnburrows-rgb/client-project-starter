# Architecture Decision Records (ADRs)

Every significant technical or business decision gets a dated ADR in this folder.

Format: `NNNN-short-title.md`

Contents:
- Date
- Status (proposed / approved / superseded)
- Context
- Decision
- Consequences

Start with `0001-repo-based-agent-memory.md` from `dev-firm-compass/decisions/0001-repo-based-agent-memory.md`.
