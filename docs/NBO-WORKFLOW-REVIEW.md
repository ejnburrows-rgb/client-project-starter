# NBO Workflow Review

Use this for the first 20-minute review. The goal is not to sell software; it is to identify the smallest operating change worth implementing.

## Intake

- Business:
- Website:
- Team size / roles involved:
- English / Spanish customer or staff needs:
- Current CRM, phone, email, calendar and file tools:
- One workflow that feels messy, repetitive or hard to supervise:
- Where work, leads, files or follow-up currently get lost:
- What the owner or manager cannot see clearly today:

## Map the current workflow

1. Trigger — what starts the work?
2. Intake — where does the information arrive?
3. Ownership — who is responsible next?
4. Handoffs — where does the work change hands?
5. Files / data — where is the information stored?
6. Follow-up — what currently depends on memory?
7. Management visibility — what needs attention and who sees it?
8. Completion — what proves the work is actually finished?

## Decide the smallest useful change

Choose one:
- Workflow Reset
- Operations System Build
- Bilingual AI Operations Layer

Define:
- What changes
- What stays in the client's existing tools
- What becomes automated
- What remains human-controlled
- English / Spanish requirements
- Acceptance criteria
- Evidence required before calling it complete

## Output

End the review with one bounded recommendation, not a broad transformation plan.
